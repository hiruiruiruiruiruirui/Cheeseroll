高等数学 6/8
求极限：lim(x→0) (sin x - x) / x³
答案： 使用泰勒展开：sin x = x - x³/6 + O(x⁵)，代入得 lim(x→0) ( -x³/6 ) / x³ = -1/6

大学物理 6/7
两块带电平行板之间的电场强度如何计算？
答案： E = σ / ε₀，其中 σ 为面电荷密度，ε₀ 为真空介电常数。方向垂直于板面。

数据结构 6/6
红黑树与 AVL 树的主要区别是什么？
答案： AVL 树追求严格平衡（平衡因子 ≤ 1），插入删除需要更多旋转；红黑树允许一定不平衡，插入最多 2 次旋转，删除最多 3 次旋转，综合性能更优。

有机化学 6/5
SN1 与 SN2 反应机理的核心区别？
答案： SN1：两步反应，先形成碳正离子中间体，后亲核进攻；适合叔卤代烷。SN2：一步协同反应，亲核试剂背面进攻，构型翻转；适合伯卤代烷。
